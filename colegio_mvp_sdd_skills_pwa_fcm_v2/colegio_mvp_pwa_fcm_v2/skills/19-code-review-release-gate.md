# Skill 19 — Code Review & Release Gate

## Objetivo
Hacer una revisión final enfocada en riesgos del MVP.

## Revisar
1. SDD vs implementación.
2. Dependencias no autorizadas.
3. Secrets/keys accidentales.
4. Ownership en cada endpoint.
5. Transacciones bulk.
6. Deduplicación de alertas.
7. FCM token lifecycle.
8. Payload Push privacy.
9. Service worker cache scope.
10. Migraciones desde cero.
11. Seed demo.
12. Build frontend.
13. Suite P0.
14. Deploy smoke test.

## Resultado
Emitir:
- PASS/FAIL;
- bloqueadores;
- riesgos aceptados;
- pasos exactos para release.
