# Skill 05 — Frontend Architecture & UX

## Objetivo
Construir React/Vite/TypeScript rápido, responsive y sin duplicación innecesaria.

## Tareas
1. Layout y routing por áreas.
2. API client central.
3. Auth state mínimo.
4. Guards de UX por rol.
5. Componentes comunes de tabla/formulario/errores.
6. Responsive: tutor mobile-first; docente/admin desktop/tablet.
7. Estados loading/empty/error.

## Reglas
- Backend sigue siendo autoridad.
- No guardar refresh largo en localStorage.
- No usar un store global para cada formulario.
- No introducir una librería grande si el flujo puede resolverse simple.

## DoD
Build de producción + rutas P0 operativas.
